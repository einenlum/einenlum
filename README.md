- [parisian-libraries](https://github.com/einenlum/parisian-libraries) (**TypeScript**): An unofficial SDK to search through Parisian libraries
- [cashier-paddle-webhooks](https://github.com/einenlum/cashier-paddle-webhooks) (**PHP**): A package to automatically listen to Paddle Webhooks in local development with Laravel Cashier
